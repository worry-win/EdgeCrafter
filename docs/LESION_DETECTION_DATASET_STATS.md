# Lesion Detection 数据集类别统计

统计对象为 `/cobot/Data/Lesion_det` 下四个检测数据集的原始 COCO 标注：

- `det_breast`
- `det_liver`
- `det_kidney`
- `det_thyroid`（需求中的 `det_thyriod` 实际目录名为 `det_thyroid`）

类别表中的 `train`、`valid`、`test` 和 `总计` 均采用 `图片数/框数` 格式。图片数是对应 split 中至少包含一个该类别框的唯一 `image_id` 数，框数是该类别的 annotation 数量；“全部类别”行的图片数是至少包含一个任意类别框的去重图像数。统计直接使用各目录 `annotations/{train,valid,test}.json`，不包含 liver 的 `*_ignore_9_12.json` 派生标注。

## 数据检查备注

- 四个数据集共包含 95,153 张 split 图像、98,446 个标注框。
- 所有 annotation 的 `category_id` 都存在于对应 JSON 的 `categories` 中。
- 所有 bbox 均包含四个坐标值，且宽、高为正数。
- `det_breast` 的类别 ID 不连续，原始 ID 中没有 `0` 和 `4`。
- `det_liver` 的 ID 7 和 10 在三个 split 中均无标注框；ID 9、11、12 的 label 分别为原始字符串 `16`、`18`、`19`。
- `det_kidney` 的 ID 4 原始 label 为 `i`，并且 valid split 中没有该类标注。
- `det_thyroid` 的 ID 3 原始 label 为 `25`；ID 2 在 test split 中没有标注。
